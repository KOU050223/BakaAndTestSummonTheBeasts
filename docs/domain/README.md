# ドメイン用語

このディレクトリでは、プロジェクト内で使うユビキタス言語を境界付けられたコンテキストごとに定義する。

ユビキタス言語は単なる用語集ではなく、ドメインエキスパートと開発者が同じ文脈で同じ意味を扱うための言葉である。用語を定義するときは、言葉そのものの一般的な意味ではなく、アクター、目的、文脈、ルールを明確にする。

## コンテキスト

- [アカウント](./contexts/account.md): ユーザー、アカウント、認証、プロフィール
- [クラス編成](./contexts/classroom.md): 生徒、教師、クラス、所属
- [試験](./contexts/exam.md): 試験、科目、点数、成績
- [バトル](./contexts/battle.md): バトル、ターン、行動、勝敗、状態
- [召喚獣](./contexts/summon.md): 召喚獣、召喚、ステータス、能力

## 分割の考え方

- 分割単位は `frontend`、`backend`、`game` などの技術構成ではなく、言葉の意味やルールが変わる業務文脈に合わせる。
- 同じ単語でも文脈が違えば別の定義として扱う。
- 迷ったら「その用語を取り巻くルールが別物か？」で判断する。
- まだ判断できないものは無理に確定せず、未決事項として残す。

## 用語の記述フォーマット

```markdown
### <用語>

- 定義:
- アクター:
- 目的:
- 文脈:
- ルール:
- 含まないもの:
- 例:
- 反例:
- 関連語:
- 実装・テストへの影響:
- 未決事項:
```
