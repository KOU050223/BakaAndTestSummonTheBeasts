# 試験コンテキスト

試験、科目、点数、成績、採点フィードバックを扱う文脈。

## 参照元

- Wikipedia「バカとテストと召喚獣」では、試験召喚システムに対応したテストは点数上限が存在せず、複数教科と総合科目があると説明されている。
- 同ページでは、召喚獣の力は該当科目で直近に受けたテストの点数に比例すると説明されている。

## 用語

### 試験

- 定義: 教師が科目・対象クラス・満点を指定して登録し、生徒の点数を記録する評価イベント。
- アクター: 教師、学校管理者、生徒。
- 目的: 生徒の学習成果をデータ化し、フィードバックと召喚獣ステータス計算に使う。
- 文脈: 試験作成、点数入力、成績確認、召喚獣ステータス再計算。
- ルール:
  - MVPでは1試験につき1科目を扱う。
  - MVPでは100点満点を基本とし、試験ごとの満点設定を100点換算する。
  - 教師が採点済み答案をもとに点数を手動入力する。
  - 入学試験によるクラス振り分けはMVPでは扱わない。
- 含まないもの: バトルそのもの、召喚獣そのもの、学習教材。
- 例: 数学 小テスト1、英語 期末試験。
- 反例: 1対1バトル、召喚フィールド、クラス設備。
- 関連語: 科目、点数、成績フィードバック、召喚獣ステータス。
- 実装・テストへの影響: 試験作成、満点設定、対象クラス、点数登録後のステータス再計算をテストする。
- 未決事項: 追試、欠席、途中退席、無記名答案をどう扱うか。

### テスト

- 定義: 原作・アニメ世界で試験召喚システムに対応する学力試験。
- アクター: 生徒、教師。
- 目的: 試召戦争で使う点数を得る。
- 文脈: 原作・アニメ準拠の用語、将来の試召戦争。
- ルール:
  - 原作・アニメでは点数上限がなく、時間内に無制限に問題を解ける。
  - 本プロダクトのMVPでは「試験」として100点換算の通常試験に置き換える。
- 含まないもの: 採点済み答案の画像、バトル行動。
- 例: 召喚獣の力の根拠になる科目テスト。
- 反例: バトル中の通常攻撃、ログイン認証。
- 関連語: 試験、点数、科目、補充試験。
- 実装・テストへの影響: コード上は原則 `Exam` を使い、原作説明や表示文言で必要な場合に「テスト」を使う。
- 未決事項: 将来、原作準拠の無制限テストをゲーム内イベントとして実装するか。

### 科目

- 定義: 試験とバトルで点数・能力計算の対象になる学習分野。
- アクター: 教師、生徒、学校管理者。
- 目的: 点数と召喚獣ステータス、バトルの対戦条件を紐づける。
- 文脈: 試験作成、点数入力、召喚獣ステータス、バトル作成。
- ルール:
  - MVP対応科目は、英語、数学、物理、化学、生物、地学、地理、日本史、世界史、現代社会、国語。
  - 原作・アニメに存在する古典、保健、体育、総合科目はMVPでは対象外とする。
  - 各バトルは作成時に1つの対戦科目を指定する。
- 含まないもの: クラス、ロール、設備。
- 例: 数学、英語、日本史。
- 反例: Fクラス、通常攻撃、HP。
- 関連語: 試験、点数、対戦科目、総合科目。
- 実装・テストへの影響: 科目IDの列挙、未対応科目の拒否、科目別の最新点数取得をテストする。
- 未決事項: 国語を現代国語・古典に分けるか。総合科目をいつ扱うか。

### 点数

- 定義: 生徒が試験で得た数値評価で、召喚獣ステータスの根拠になる値。
- アクター: 生徒、教師。
- 目的: 学習成果を可視化し、召喚獣の強さへ反映する。
- 文脈: 採点入力、成績確認、ステータス計算、バトル開始データ。
- ルール:
  - RailsとPostgreSQLに保存された点数を正本とする。
  - MVPでは試験ごとの満点から100点換算して扱う。
  - 召喚獣ステータスは各科目の最新点数をもとに再計算する。
  - 原作・アニメでは戦闘消耗により点数が減るが、MVPでは成績データとしての点数はバトル中に減らさない。
- 含まないもの: バトル中HP、経験値、ゲーム内通貨。
- 例: 数学82点、英語74点。
- 反例: HP120、攻撃30、勝敗結果。
- 関連語: 成績、試験、召喚獣ステータス、HP。
- 実装・テストへの影響: 点数入力範囲、100点換算、最新点数の選択、ステータス再計算をテストする。
- 未決事項: 欠席・未提出・採点保留を0点と別状態にするか。

### 成績フィードバック

- 定義: 採点後に、生徒へ点数と召喚獣ステータス変化を返すこと。
- アクター: 生徒、教師。
- 目的: 生徒が学習成果と次の改善対象を確認できるようにする。
- 文脈: 生徒画面、教師の点数登録後、召喚獣ステータス表示。
- ルール:
  - 生徒は自分の点数、対象科目、試験名、登録日を確認できる。
  - 生徒は点数に基づいて再計算された召喚獣ステータスを確認できる。
  - 教師はクラス単位で登録済み点数を確認できる。
- 含まないもの: AI採点支援、学習計画、教材推薦。
- 例: 数学 小テスト1の点数と更新後HPの表示。
- 反例: バトルリザルトだけの表示。
- 関連語: 試験、点数、召喚獣ステータス。
- 実装・テストへの影響: 生徒本人向け表示と教師向けクラス一覧の権限差をテストする。
- 未決事項: フィードバックに平均との差、順位、コメントを含めるか。

### 補充試験

- 定義: 原作・アニメで、試召戦争中に消耗した点数を回復するためのテスト。
- アクター: 生徒、教師。
- 目的: 戦闘不能に至らないよう点数を補給し、戦争へ復帰する。
- 文脈: 原作・アニメ準拠の試召戦争、将来スコープ。
- ルール:
  - MVPでは実装しない。
  - MVPの点数は成績データであり、バトル中に消費・回復しない。
- 含まないもの: 通常の試験、追試、補習。
- 例: 試召戦争中の補給テスト。
- 反例: 数学 小テスト1の通常採点。
- 関連語: 点数、戦死、補習、試召戦争。
- 実装・テストへの影響: 将来実装時は、成績としての点数と戦争中リソースとしての点数を別モデルにする。
- 未決事項: 補充試験を教育的な再テストとして実装するか、ゲーム内回復手段として実装するか。
